This is a video player. but with a difference...
you can watch a movie with someone else easily using this video player with cync option. using cync option you both can select a video file locally and then choose a time to play the movie. then the movie will be played at the exact time you both set and the movie 

--------------------------------------IMPORTANT--------------------------------------
You need to have vlc installed on your computer so this program will work.
If you see any errors on launch that's because you probably don't have vlc installed.
If you have any vlc version installed but the program is still not working please download and install this versios fro the link below:
https://videolan.mirror.liteserver.nl/vlc/3.0.21/win64/vlc-3.0.21-win64.exe
